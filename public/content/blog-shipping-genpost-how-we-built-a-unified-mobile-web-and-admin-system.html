Building a mobile app is hard. Building a synchronous ecosystem that works flawlessly across iOS, Android, the Web, and includes a Super Admin dashboard for management? That is a massive undertaking.

Yet, that is exactly what we accomplished with Genpost.

We didn't just want to ship an MVP (Minimum Viable Product); we wanted to ship a fully fledged product. A product complete with credit systems, subscription tiers, social sharing, and a robust backend. Here is a look behind the curtain at how we designed and developed the Genpost ecosystem.

1. The Vision: Simplicity Meets Power

Looking at the interface, our goal was clarity. We entered a crowded market of AI generation tools, so the UI had to be intuitive.

  • The Feed (Discovery): We built a visually immersive home feed (left screen) that encourages exploration. The "Generate New" action is always within thumb's reach, floating clearly over the content.
  • The Feedback Loop: AI generation takes time. We designed the generation screen (middle) to handle loading states gracefully, resulting in a "Generation Completed" success state that immediately offers options to Edit, Download, or Share to socials.

2. The Tech Stack: One Codebase, Everywhere

To ship for iOS, Android, and Web simultaneously without tripling our team size, we relied on a cross-platform architecture (likely Flutter or React Native). This allowed us to:

  • Share Logic: The logic for deducting tokens ("12 Left") and managing state is written once and deployed everywhere.
  • Unified UI: The clean, rounded card aesthetics and the distinctive orange branding remain consistent whether the user is on an iPhone, a Samsung, or a Chrome browser.

3. The Business Logic: Monetization & Subscriptions

A "fully fledged" app isn't just about features; it's about business viability. As seen in the Profile screen (right), we integrated a robust payment gateway (like Stripe or RevenueCat) to handle the Pro Plan.

  • Tiered Access: We implemented logic to handle the "$99.99/month" subscription which grants 1M tokens.
  • Toggle Logic: Features like "Opt out of global share" required strict backend permissions—ensuring that paid users have privacy controls that immediately propagate to the server.

4. The Invisible Engine: The Admin Dashboard

While the screenshots show the user-facing mobile app, the backbone of this project is the Admin Dashboard and role-based web app we built alongside it.

To manage the app effectively, we built a comprehensive dashboard that handles:

  • User Management: Viewing profiles like "Dagmawi Esayas," resetting passwords, or managing bans.
  • Financial Oversight: Tracking the recurring revenue shown in the subscription screen.
  • Content Moderation: Since users are generating content globally, the Admin role allows us to monitor the public feed for safety.

5. Lessons Learned

Shipping this multi-platform system taught us three key things:

  1. State Management is King: Keeping the "Token Counter" (12 Left) in sync across the web app and the mobile app in real-time was a challenge that required robust socket connections or efficient API polling.
  2. Native Feel Matters: Even though we used cross-platform tech, we ensured the navigation and gestures felt native to both iOS and Android.
  3. Scalability First: By separating our "Genpost" core engine from the client apps, we can now update the AI models in the background without forcing users to update their apps.

Conclusion

Genpost is more than just an image generator; it’s a testament to modern full-stack development. By strictly prioritizing a unified design system and a scalable architecture, we were able to ship a complete ecosystem—Mobile, Web, and Admin—ready for the world to use.
