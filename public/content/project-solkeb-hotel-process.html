Solkeb Hotel in Jijiga needed everything at once: guest Wi-Fi that actually works on every floor, cameras with no blind spots, internal phones, and a proper server room to run it all — delivered for a ground-plus-five property that was welcoming guests throughout the work. Managed Wi-Fi across six floors We designed a TP-Link Omada managed network with access points placed for seamless roaming from the lobby to the top floor. Guests connect once and stay connected; staff devices run on a separate, secured network segment. 32 cameras, zero blind spots The CCTV design started from a blind-spot analysis, not a camera count. 32 cameras cover entrances, corridors, parking, and service areas, with recording sized for the retention the management required and remote viewing configured for the owners. PBX and the mini server room A PBX system connects the front desk, housekeeping, kitchens, and management offices over the same structured cabling plant. Everything terminates in a purpose-built mini server room — rack-mounted, labeled, cooled, and documented so the hotel's own staff can hand it to any technician in the future.
